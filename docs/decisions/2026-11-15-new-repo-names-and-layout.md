# 2026-11-15 — Repo nuevo, nombres y organización

**Qué se decidió** (Lucas)

- La línea vive en un repo nuevo y público, `essence-of-discovery`. El anterior, `research-worlds-envs`
  (proyecto WAGER), queda como biblioteca y se archiva cuando este funcione.
- El repo lleva el nombre de la pregunta. Cada juego lleva el suyo; el primero es `jump-ahead`.
- Nombres de carpetas y archivos en inglés. El contenido de los documentos, en castellano.
- En la raíz va solo lo oficial. Abajo: `games/` (código), `experiments/` (corridas), `docs/` (lo
  vigente) y `research/` (material de trabajo; lo traído del repo viejo, en `research/legacy/`).
- Se trajo del repo viejo la investigación que sirve acá: 27 documentos, congelados.

**Por qué**

- El repo viejo tiene demasiado material y reglas de otro proyecto: cada sesión arrancaba pensando con
  el vocabulario viejo.
- Si un juego no da señal, el siguiente va al mismo lugar y el repo no queda huérfano.

**Qué se descartó**

- Renombrar el repo viejo y seguir ahí: demasiadas cosas viejas.
- Un archivo único de decisiones en la raíz: crece sin tope y la raíz deja de ser "lo oficial".
